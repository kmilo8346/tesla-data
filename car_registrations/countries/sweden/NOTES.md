# Suecia (Mobility Sweden) — notas

## Nombre del archivo

El Excel de cada mes está en el artículo mensual de
https://mobilitysweden.se/statistik/Nyregistreringar_per_manad_1. El nombre cambió con el tiempo:

| Meses | Ejemplo |
|---|---|
| 2023 | `Nyregistreringar december 2023.xlsx` |
| 2024-01 a 2026-07 | `Månadsrapport Nyregistreringar juli 2026.xlsx` |
| 2025-12 | `Månadsrapport Nyregistreringar december 2025 (prel).xlsx` |
| desde 2026-08 | `Månadsrapport Nyregistreringar sep 2026.xlsx` (mes abreviado) |

## Diciembre preliminar

Para diciembre se guarda el Excel del primer artículo de enero, que es **preliminar**
(en 2025 lo dice el nombre: `(prel)`). Mobility Sweden publica después, en otro artículo
("Definitiva nyregistreringar under AAAA"), las cifras definitivas del año. No se usan, para
mantener el mismo criterio en todos los meses.
